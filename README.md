# Аналітична платформа для моніторингу цін на паливо України та валютних курсів

## Опис проєкту
Цей проєкт є **Data Engineering рішенням**, яке реалізує **ETL pipeline** на основі 
**медальйонної архітектури (Bronze – Silver – Gold)** для обробки, збереження та аналітики даних про:
- щоденні ціни на паливо в Україні (середні та за брендами) зі сайту [https://index.minfin.com.ua/ua/markets/fuel/](https://index.minfin.com.ua/ua/markets/fuel/detail/)
- офіційні курси валют НБУ
- інформацію про заправки (локація, наявність кафе, мийки, магазину — дані згенеровані ШІ).

Система забезпечує **автоматизоване завантаження, трансформацію, очищення та збереження даних** у 
вигляді зручної **зіркової схеми (Star Schema)** для подальшої аналітики у **Power BI**.

## Архітектура трансформацій даних
- **Bronze (інкрементальні дані)**  
  - Дані завантажуються з джерел:  
    - **Веб-скрапінг** — сайт [Ціни на паливо (Minfin)](https://index.minfin.com.ua/ua/markets/fuel/reg/vinnickaya/2025-01/) (*історичні та щоденні дані*).  
    - **API** — [НБУ курси валют](https://bank.gov.ua/NBUStatService/v1/statdirectory/exchange?json).  
      - Використовується параметр: якщо дані *щоденні* — виконується *copy activities*,  
        у випадку *історичних* — застосовується окремий код для обробки.  
    - **CSV-файли** — розміщені у репозиторії GitHub.  
  - Зберігаються у форматі *Parquet* у Data Lake.  
  - Приклади: середні ціни на паливо, ціни по брендах, історичні курси валют.

- **Silver (очищення та трансформації у Databricks)**  
  - Середні ціни палива — нормалізація, приведення типів, видалення пропусків, завантаження в Delta Lake.  
  - Бренди — трансформація з long → wide формат, очищення від дублікатів, додавання року/місяця/дня.  
  - Курси валют — відбір USD, EUR, PLN, XAU, XAG, XPT, XPD; приведення дат, очищення та видалення дублікатів.  
  - Усі дані логуються у Delta таблицях.

- **Gold (аналітичний рівень, Azure SQL Database)**  
  - **Середні ціни палива**: інкрементальне завантаження у SQL без дублікатів.  
  - **Курси валют**: аналогічне інкрементальне завантаження.  
  - **Бренди**: додаткове збагачення даними про валютні курси (грн, USD, EUR), розділення на вимірні таблиці (*dim_region, dim_brand, dim_fuel_type*) та факт (*fact_fuel_price*) з surrogate keys.

## Ключові компоненти
- **Azure Data Factory** – оркестрація пайплайнів (щоденний запуск, моніторинг).  
- **Azure Databricks** – основні ETL/ELT трансформації.  
- **Azure Data Lake Storage** – зберігання Bronze/Silver даних.  
- **Azure SQL Database** – зберігання Gold рівня (Star Schema).  
- **Azure Key Vault** – безпечне збереження секретів та доступів.  
- **Power BI** – візуалізація даних:
  - карта заправок і їх кількість;
  - щоденні ціни на паливо по регіонах, брендах та типах палива;
  - динаміка зміни курсу та вартості палива за період та максимальні курси валют;

## Логування та моніторинг
- Кожен етап трансформацій супроводжується логуванням у Delta Lake:  
  - статус (успіх/пропуск/помилка);  
  - кількість оброблених рядків;  
  - джерело даних (historical/daily).  
- Це дозволяє відстежувати якість пайплайнів та контролювати інкрементальні завантаження.

## Технології
- **Мова програмування:** PySpark, SQL  
- **Хмарні сервіси:** Azure Data Factory, Azure Databricks, Azure Data Lake, Azure SQL Database, Azure Key Vault  
- **Формати даних:** Parquet, Delta  
- **Візуалізація:** Power BI

## Результат
Проєкт дозволяє:
- централізовано зберігати історію змін цін на паливо та курсів валют;
- автоматизувати ETL процеси за допомогою Azure;
- побудувати аналітичну **зіркову схему** для ефективної бізнес-аналітики;
- забезпечити масштабованість для нових джерел даних (наприклад, розширення по локаціях або нових типах валют/палива).
